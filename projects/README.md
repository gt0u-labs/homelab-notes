# Projects

This folder contains small practical homelab projects focused on Linux, Docker, networking and troubleshooting.

Each project documents the goal, environment, commands used, result and lessons learned.

> **Note on environment history:** the earliest projects here were done on Windows 11 Pro + WSL Ubuntu, before the infrastructure migrated to a dedicated two-node setup (Ubuntu Server + Proxmox VE). Each project's "Environment" section reflects what was actually used *at the time* — see the [main README](../README.md) for the current lab setup.
